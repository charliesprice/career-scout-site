A search needs Claude: it searches the web, opens each posting, checks whether you can apply and scores it. This page can't do that itself, because it never goes online. Paste this into Claude (the Code tab in the Claude app, or Claude Code):

Refresh my job search with career-scout, then rebuild my career-scout site.

When it finishes, reload this page. New results get a New tag. If you set up a scheduled refresh, it runs by itself and this page will already be up to date when you open it.
